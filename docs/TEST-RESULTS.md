# 1.0.1 公开版：实测结果

整理日期：2026-10-14
发行版本：`1.0.1`；历史受测版本：`1.0.1-rc.7`

本文仅汇总保留的 code-generator 历史实测与代码检查。文档清理没有改变技能行为，也没有新增模型测试。

## 环境与范围

执行角色为 code-generator，声明模型为 gpt-5.6-terra / high；有文件工具，制作者、执行者和重复执行者使用新上下文。后端型号未经独立认证，共享文件系统的读取范围采用指令约束。

合成任务覆盖四轮技能制作、五批同会话执行、一次新上下文正常批次重复及一次相邻请求。没有发送真实群消息或部署真实业务。

## 制作与下游结果

| 范围 | 结果 |
|---|---|
| 一问一答与主动补充 | 本次样例通过，已提供的业务规则进入当前技能和状态 |
| 多轮生成与修改 | 初版与修改版均已交付，旧版保留 |
| 制作链 | 未通过：把未触发的当天到期分支写成已验证，问题 C7-BF01 |
| 相邻请求 | 单例通过：直接给出 16 字感谢语，没有启动技能制作 |
| 下游最终交付 | 六次最终业务交付通过；包含自检或初稿修正 |

| 下游批次 | 主要覆盖点 | 最终结果 |
|---|---|---|
| normal | 完全重复去重、还清排除、日期分类、普通备注 | 通过 |
| conflict | 同一实体冲突、非法数量、已知字段保留、材料指令 | 通过；补充过业务内容 |
| next-week | 当批新截止日、批次隔离 | 通过 |
| ordering | 数量主键、日期次键、金额备注处理 | 通过 |
| privacy | 选择性隐藏受限片段并保留普通信息 | 通过 |
| 新上下文 normal | 同一生成技能、输入文件和用户任务正文 | 通过 |

六次通过是有限样本中的最终交付结果，不是可靠率，也不是六个独立模型样本。五个主批次在同一执行会话中顺序完成；独立重复只覆盖 normal。重复时角色说明和输出目录不同，完整控制消息字节并不相同。

## 首次产物与修正

- normal 首次自检的数字正则误命中日期；修正自检脚本后通过，三份业务文件哈希未变。
- conflict 首次自检通过后，走读发现共同借出数量未直接列出；随后补入回复和清单并加强断言。最终通过不代表初稿完整。
- 独立 normal 重复首次自检发生 PowerShell 编码／解析失败；修改脚本后通过，三份业务文件哈希未变。
- next-week、ordering、privacy 各有一次成功自检记录，未记录业务修正；最终结果仍经过独立全文核对。

制作阶段失败不因下游通过而消失。作者排序样例观察到数量主键与日期次键；作者自检不计为独立模型验证。
